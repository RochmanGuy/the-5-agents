# Reference — דוגמאות לטקסטים בסגנון שלנו

זרקו לכאן קבצי `.md` או `.txt` עם דוגמאות לטקסטים שכבר נכתבו בסגנון של הצוות. יעל קוראת את כל הקבצים בתיקייה הזו בתחילת כל משימה (`Glob yael/reference/**/*`) ומשתמשת בהם כדוגמאות חיות לכיוון הסגנוני שאליו צריך לכוון.

## איך לבחור דוגמאות

- העדיפו טקסטים **שאתם מרוצים מהם** — לא טיוטות.
- שילוב של פורמטים: מאמר ארוך, פוסט בלוג קצר, ניוזלטר, סיכום.
- אם יש דוגמאות "אל תכתבו ככה" — שמרו בקובץ נפרד עם prefix `anti-` (למשל `anti-corporate.md`).

## פורמט

אין דרישת פורמט פנימי — סתם markdown או טקסט. יעל קוראת את התוכן.
