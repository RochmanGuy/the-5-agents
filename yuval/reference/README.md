# yuval/reference/

תיקיית reference של **יובל** — מקור הסגנון לכל התמונות שייווצרו בפרויקט.

## מה לשים פה

- **תמונות השראה** (`.png`, `.jpg`, `.jpeg`, `.webp`) — דוגמאות לסגנון, פלטה, mood, קומפוזיציה.
- **הערות סגנון** (`.md`, `.txt`) — הוראות בכתב על סגנון הצוות. דוגמה: "כל התמונות בסגנון flat illustration, פלטה pastel, ללא צללים".

יובל יקרא את התיקייה הזו בתחילת כל בקשת תמונה.

## איך יובל קורא את התיקייה

- **קבצי טקסט** (`.md`, `.txt`) — קורא במלואם.
- **קבצי תמונה** — לא פותח, אבל **שמות הקבצים** משמשים כ-signal. לכן שמות תיאוריים: `flat-illustration-blue-sunrise.png` מסר יותר מ-`IMG_1234.png`.

## מתי לעדכן

בכל פעם שראובן או המשתמש רוצים שינוי כיוון בסגנון של הצוות:
1. הוסיפי קבצים חדשים (תמונות + הערה ב-`.md`).
2. עדכני / מחקי דוגמאות ישנות שכבר לא מייצגות את הסגנון.

יובל תמיד עובד עם **המצב הנוכחי** של התיקייה.
