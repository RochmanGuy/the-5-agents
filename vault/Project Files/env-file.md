# .env

## מה זה
הקובץ הסודי בפועל. מכיל מפתחות API אמיתיים. **לא** נמצא ב-git (מסומן ב-`.gitignore`).

## למי משויך
**ראובן** — שומר על הסודות; שאר הסוכנים צורכים את הערכים אבל לא נוגעים בקובץ.

## נתיב
`.env` (שורש הפרויקט, גיט-איגנור)

- [[env-example]] — התבנית שעליה הוא מבוסס
- [[gitignore]] — שורת `.env` שם מונעת דלף סודות
