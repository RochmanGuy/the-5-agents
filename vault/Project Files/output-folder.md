# Output/

## מה זה
תיקיית הפלט של יעל. בכל שכתוב, יעל מייצרת **שני קבצים** בשם המקורי של המאמר:
- `<name>.md` — Markdown נקי, מוכן להעתקה.
- `<name>.html` — HTML עצמאי (single-file, CSS inline) מעוצב לקריאה בנוחות בדפדפן.

## למה שני פורמטים
- **Markdown** — לפרסום בפלטפורמות שמקבלות MD (GitHub, רוב ה-CMS המודרניים, Substack, וכו').
- **HTML** — לפתיחה מיידית בדפדפן לקריאת הגהה / שיתוף / archive.

## מצב נוכחי
ריקה (רק `.gitkeep`). תתמלא בתוצרי שכתוב.

## למי משויך
**יעל** — כותבת.
**ראובן** / המשתמש — צורכים את הפלט (קוראים, מעבירים הלאה לעיצוב / פרסום).

## נתיב
`Output/` (תחת שורש הפרויקט)
