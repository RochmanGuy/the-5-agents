# CLAUDE.md

## מה זה
קובץ ההגדרות הראשי של Claude Code בפרויקט. נטען אוטומטית לכל סשן ומכתיב את ההתנהגות.

## מה כתוב בו
- מגדיר את **ראובן** כמנכ"ל ונקודת הכניסה לבקשות.
- מתאר את הצוות: **יעל** (כתיבת תוכן), **יובל** (עיצוב חזותי), **חן** (חקר).
- **הוראות ניתוב** עם תת-סעיף ליעל ותת-סעיף ליובל — מתי להפעיל, trigger keywords עברית+אנגלית, כלים, נתיב סוכן.
- **תהליכים משולבים** — תהליך "מאמר עם תמונות" שבו ראובן מתאם בין יעל ויובל (יעל משאירה placeholders של `{{IMAGE_NEEDED}}`, ראובן מפעיל את יובל למלא, ראובן משלב חזרה ב-Output).
- מפרט את מבנה התיקיות: `.claude/agents`, `.claude/skills`, `.claude/commands`, וגם תיקיות העבודה מחוץ ל-`.claude/` (`yael/`, `yuval/`, `Content/`, `Output/`).

## למי משויך
**ראובן** — מסמך השרשרת של הצוות; הוא מקבל את הבקשה ומחליט את מי להפעיל לפי המסמך הזה.
