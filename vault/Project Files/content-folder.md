# Content/

## מה זה
תיקיית הקלט של יעל. כאן מונחים **מאמרי גלם** שממתינים לשכתוב. כל קובץ הוא מאמר אחד, פורמט Markdown מועדף (אבל גם טקסט נקי עובד).

## איך זה עובד
1. ראובן (או המשתמש ישירות) מניח מאמר ב-`Content/`.
2. ראובן מפעיל את [[yael-agent|יעל]] עם בקשת שכתוב.
3. יעל קוראת את הקובץ, משכתבת, ושומרת לתוך [[output-folder]].
4. המאמר המקורי **נשאר** ב-`Content/` (יעל לא מוחקת קלטים).

## מצב נוכחי
ריקה (רק `.gitkeep`). תתמלא במאמרי גלם בהתאם לזרימת העבודה.

## למי משויך
**יעל** — צורכת.
**ראובן** / המשתמש — ממלאים.

## נתיב
`Content/` (תחת שורש הפרויקט)

## קבצים קשורים
- [[yael-agent]] — הסוכן שצורך את התיקייה הזו
- [[output-folder]] — תיקיית הפלט המקבילה
- [[yael-folder]] — תיקיית ה-context הסגנוני של יעל
