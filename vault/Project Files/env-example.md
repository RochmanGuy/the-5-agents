# .env.example

## מה זה
תבנית למשתני סביבה. מי שמפעיל את הפרויקט מעתיק אותו ל-`.env` וממלא את הערכים האמיתיים.

## מה כתוב בו
- `ANTHROPIC_API_KEY` — נדרש עבור כל סוכני הצוות (Claude API).
- `OPENAI_API_KEY` — אופציונלי, ליצירת תמונות (משויך ל**יובל**).
- `TAVILY_API_KEY` — אופציונלי, למחקר (משויך ל**חן**).
- `DEFAULT_MODEL=claude-opus-4-7` — המודל הדיפולטי לסוכנים.
- `LOG_LEVEL` — רמת הלוגים.

## למי משויך
**ראובן** (תשתית) — אך כל מפתח קי משויך לתפקיד: Anthropic = הצוות כולו, OpenAI = יובל, Tavily = חן.

## נתיב
`.env.example` (שורש הפרויקט)
