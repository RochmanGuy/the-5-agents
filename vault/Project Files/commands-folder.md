# .claude/commands/

## מה זה
תיקיית פקודות מותאמות (slash commands) שמפעילות זרימות עבודה מוגדרות מראש. **כרגע ריקה** (רק `.gitkeep`).

## מה אמור להיות שם
כל קובץ `.md` כאן הופך לפקודה `/<name>`. למשל פקודה `/produce-post` שמפעילה את חן → יעל → יובל ברצף.

## למי משויך
**ראובן** מגדיר את הפקודות (זרימות הניהול). הצוות כולו צורך אותן.

## נתיב
`.claude/commands/`

## קבצים קשורים
- [[claude-md]] — מתאר את חלוקת התפקידים שהפקודות יתאמו ביניהם
- [[agents-folder]] — פקודה לרוב מפעילה סוכנים מהתיקייה הזו
- [[skills-folder]] — פקודה יכולה לקרוא ל-skill ספציפי
