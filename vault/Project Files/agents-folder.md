# .claude/agents/

## מה זה
תיקייה שבה יושבים הגדרות הסוכנים של הצוות.

## מה יש שם כרגע
- [[yael-agent]] — כותבת התוכן. הסוכן הראשון של הצוות שהוגדר בפועל (2026-05-13).
- [[yuval-agent]] — מעצב התמונות. הסוכן השני שהוגדר בפועל (2026-05-13).

## מה אמור עוד להיכנס
- `chen.md` — החוקרת (טרם הוגדרה)

## למי משויך
**ראובן** מגדיר את הסוכנים. **יעל / יובל / חן** הם הישויות שמוגדרות כאן.

## נתיב
`.claude/agents/`

## קבצים קשורים
- [[claude-md]] — מתאר את הצוות ואת הוראות הניתוב (מתי להפעיל את מי)
- [[yael-agent]] — קובץ ההגדרה של יעל
- [[yael-folder]] — תיקיית העבודה של יעל (style-guide, reference)
- [[yuval-agent]] — קובץ ההגדרה של יובל
- [[yuval-folder]] — תיקיית העבודה של יובל (reference, outputs)
- [[content-folder]] — תיקיית הקלט של יעל (מאמרי גלם)
- [[output-folder]] — תיקיית הפלט של יעל (קבצי MD + HTML)
- [[commands-folder]] — לעיתים פקודה מפעילה רצף של סוכנים מהתיקייה הזו
- [[skills-folder]] — היכולות שכל סוכן יכול לקרוא להן
