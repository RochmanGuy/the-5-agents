# skill: obsidian-vault-workflow

## מה זה
הפרוטוקול המחייב לעבודה עם ה-vault: Phase 1 (קריאת קובץ הנושא + Meeting Notes / Content Briefs / Brand Guidelines) **לפני** משימה, Phase 2 (כתיבת Session Log עם status tag + עדכון Overview/Open Questions + עדכון `_index.md` + verification) **אחרי** משימה.
